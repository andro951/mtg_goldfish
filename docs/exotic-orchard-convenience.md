# Exotic Orchard convenience

Astra treats **Exotic Orchard** as a five-color land by default for goldfish convenience. With **Menu → Settings → Exotic Orchard: all colors** enabled, the simulator behaves as though an opponent controls a land capable of producing W, U, B, R, or G.

The setting defaults to **on**. Turn it off to restore the rules-based modeled-opponent behavior, where Exotic Orchard derives its available colors from opponent lands and reported opponent land colors.

Older saved sessions that predate this setting also use the enabled behavior until the user explicitly disables it. Changing the setting is a normal game action, so the choice is preserved in the session and participates in undo, redo, export, import, and replay.
